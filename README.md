# Mini Calculate

A simple calculator application built using the C programming language. This project demonstrates basic arithmetic operations, input handling, and control structures in C.

## Features
* **Addition (+)** - Add two or more numbers.
* **Subtraction (-)** - Subtract numbers easily.
* **Multiplication (*)** - Multiply values instantly.
* **Division (/)** - Divide numbers with precise floating-point output.

## Technologies Used
* **Language:** C
* **Compiler:** GCC (or any standard C compiler)
* **Tools:** Git, GitHub, VS Code
